# Sicherheit

Shuno speichert alles, was du kopierst – Sicherheit hat deshalb Vorrang vor
neuen Funktionen.

## Unterstützte Versionen

Sicherheitskorrekturen gibt es nur für die **jeweils neueste Version**.
Shuno sucht selbst nach Updates und installiert nur Updates mit gültiger
digitaler Signatur.

## Eine Sicherheitslücke melden

Bitte melde Lücken **nicht** als öffentliches Issue, damit niemand sie
ausnutzen kann, bevor sie behoben sind.

- **Bevorzugt:** über GitHub privat melden – Reiter
  [Security → Report a vulnerability](https://github.com/ozevstudio/shuno/security/advisories/new).
- **Alternativ:** in Shuno unter *Einstellungen → Hilfe → Feedback senden*,
  Kategorie „Fehler“, mit dem Hinweis „Sicherheit“.

Hilfreich sind: Shuno-Version, macOS-Version, eine kurze Beschreibung und
– wenn möglich – Schritte, um das Problem nachzustellen.

## Was dann passiert

- Rückmeldung in der Regel innerhalb von **7 Tagen**.
- Bestätigte Lücken werden so schnell wie möglich behoben und im
  Changelog des Releases erwähnt – auf Wunsch mit Namensnennung.

Shuno ist ein Ein-Personen-Projekt ohne Bug-Bounty-Programm.

## Wie Shuno dich schützt

Eine verständliche Übersicht aller Schutzfunktionen, inklusive eines echten
Selbsttests, findest du in der App unter *Einstellungen → Datenschutz*.
Dort steht auch, wann Shuno überhaupt ins Internet geht.
