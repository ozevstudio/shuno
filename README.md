# Shuno – dein schlanker Clipboard-Manager

Ein nativer, schlanker Clipboard-Manager für macOS. Läuft direkt in der Menüleiste, merkt sich kopierte Texte, Links und Bilder, und macht sie jederzeit wieder griffbereit.

## Systemanforderungen

- Mac mit Apple Silicon (M1 oder neuer) — Intel-Macs werden NICHT unterstützt
- macOS 26 (Tahoe) oder neuer

## Funktionen

- **Kategorien**: Text, Links und Bilder automatisch erkannt und farblich unterschieden
- **Favoriten**: wichtige Einträge markieren und schnell wiederfinden
- **Datenschutz**: Einträge lassen sich per Schloss-Symbol verstecken — erst nach Touch ID oder Mac-Passwort wieder sichtbar
- **Menüleisten-Kurzliste**: die letzten oder manuell angepinnten Einträge direkt aus der Menüleiste kopieren, ohne das Hauptfenster zu öffnen
- **Mehrfachauswahl**: mit Shift-Klick ganze Bereiche markieren und in einem Rutsch löschen
- **Minimal-Modus**: ruhigere Darstellung mit neutralen Zeilen, nur ein leuchtender Punkt zeigt die Kategorie
- **Link-Vorschau** (optional): zeigt Titel und Favicon zu kopierten Links
- **Automatische Update-Prüfung**: einstellbares Intervall im App-Menü (nur beim Start, stündlich, alle 6 Stunden oder täglich)

## Installation

1. Neueste Version unter [Releases](../../releases) herunterladen
2. Shuno.dmg öffnen
3. Shuno.app in den Programme-Ordner ziehen (nicht im Downloads-Ordner liegen lassen)
4. Rechtsklick auf Shuno.app → Öffnen (nur beim ersten Start nötig)

## Warnhinweis beim ersten Start 

macOS zeigt beim ersten Öffnen die Meldung "Apple konnte nicht überprüfen, ob 'shuno' frei von Schadsoftware ist". Das ist normal und liegt daran, dass die App nicht mit einem kostenpflichtigen Apple Developer-Zertifikat signiert ist — kein echtes Sicherheitsproblem.

So lässt sich das umgehen:
1. Mit der rechten Maustaste auf shuno.app klicken → "Öffnen" auswählen
2. Falls dort kein "Trotzdem öffnen"-Button erscheint: Systemeinstellungen → Datenschutz & Sicherheit → nach unten scrollen → "Trotzdem öffnen" klicken

Das ist nur beim allerersten Start nötig. (auch nach Updates)

## Datenschutz

Alle kopierten Inhalte (Text, Links, Bilder) werden ausschließlich lokal auf deinem Mac gespeichert, niemals an externe Server geschickt. Zwei optionale Funktionen kontaktieren das Internet, nur wenn du sie aktiv einschaltest: die Link-Vorschau (ruft die jeweilige Webseite auf, um Titel/Favicon zu laden) und die Update-Prüfung (fragt eine kleine Textdatei ab, um auf neue Versionen hinzuweisen).

Die Link-Vorschau lässt sich in der App jederzeit ein-/ausschalten. Die Update-Prüfung läuft automatisch im gewählten Intervall und kann im App-Menü auf "Nur beim Start" gestellt werden — sie sendet dabei keine persönlichen Daten, nur eine anonyme Anfrage nach der aktuellen Versionsnummer.

Versteckte Einträge (per Schloss-Symbol) werden lokal genauso wie alle anderen Einträge gespeichert, sind aber erst nach Touch ID/Passwort-Bestätigung sichtbar und werden nie in der Menüleisten-Kurzliste angezeigt.
