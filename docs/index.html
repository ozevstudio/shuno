Ein Verlauf, der mitdenkt

Jeder Eintrag wird automatisch einsortiert und durchsuchbar gemacht.

Automatische Kategorien

Text, Links, Bilder, Code und Dokumente werden erkannt und farblich unterschieden.

Bilderkennung, offline

Text und grobe Motive in Bildern werden automatisch erkannt und durchsuchbar gemacht.

Verstecken statt löschen

Sensible Einträge lassen sich per Touch ID oder Passwort verbergen.

Papierkorb mit Frist

Gelöschtes landet erst 30 Tage im Papierkorb, bevor es endgültig verschwindet.

Überall per Tastenkürzel

Ein frei wählbares Kürzel öffnet Shuno aus jeder App heraus.
